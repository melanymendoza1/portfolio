# Melany Mendoza: portfolio

Static site. No build step.

## Deploy to melanymendoza.vercel.app
1. Upload everything in this folder (`index.html` and `img/`) to a GitHub repo.
2. In Vercel, connect that repo to the `melanymendoza` project. Framework preset: Other. Build command: empty. Output directory: `./`.
3. Every push to `main` republishes the site.
